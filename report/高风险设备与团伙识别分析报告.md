## 一、核心结论（先读这里）

### 1.1 一句话结论

90 天窗口内识别出 **2,677 台高风险设备**（含 651 台机器行为设备），聚合成 **19,479 个社区**（2,875 个带风险标签）；发现 **130 个行为指纹团伙（13 个跨社区换马甲嫌疑）**、**23 个航线高置信团伙（13 个纯套利通道型）**、**31 对跨周期团伙跃迁**；上周期团伙中 **194 个已整体消失（疑似封号/跑路）**，331 个换了设备仍在活跃。

### 1.2 五个最重要的数字

| 指标 | 数值 | 含义 |
|------|------|------|
| 高风险设备 | **2,677 台** | 规则+模型双门槛确认，建议处置 |
| 套利嫌疑设备（全额退+1小时快退） | **1,779 台** | 骗赔套利核心人群 |
| 换马甲嫌疑团伙 | **13 个跨社区指纹团伙** | 实体图拆散但行为指纹证明同伙 |
| 赔付 Top 社区 | **社区 1（172 台，12.8 万元赔付）** | 退款率 71%，多账号聚集 133 台 |
| 上周期消失团伙 | **194 个实体全消** | 处置效果验证样本 / 跑路名单 |

### 1.3 优先处置建议（按 ROI 排序）

1. **立即处置**：651 台机器行为设备（单分钟 312 单的 `87e1e1f841307fa9` 等）——自动化攻击实锤，证据链完整（含内网 IP 命中 1 台）
2. **重点核查**：社区 12（61 台五标签复合：短时批量退款 26 台 + 多账号 56 台 + 套利 13 台 + 档位聚集 42 台 + 自动支付 4 台）——职业化套利团伙定性
3. **专项排查**：2,861 台舱位套利设备（同航班同舱位批量订再 90% 退款，SC4909 航班 3 舱位 88 台设备退款率 73-94%）
4. **持续监控**：31 对跨周期跃迁团伙（转型 18 对）——甩掉部分实体但习惯延续

## 二、分析背景与数据基础

### 2.1 分析框架

本项目基于 Leiden 风险用户识别体系，对机票业务设备进行多维度风险画像：

```
设备宽表（71.6万台，140+字段）
    ↓ 规则引擎（7条）+ 6模型无监督投票（iForest/OCSVM/LOF/XGB/LGB/RF）
四层风险分层（高/中/疑似/普通）
    ↓ 中高危 21,399 台 → 导出订单明细（56.5万单，32字段）
Leiden 实体图（IP/证件/手机/userId 共享连边）→ 19,479 社区
    + 航线图（共享航线习惯）→ 航线团伙
    + 行为指纹图（MinHash+LSH）→ 指纹团伙
    + 跨周期对比 → 团伙跃迁/逃离检测
```

### 2.2 数据口径说明

- 宽表来源：`flight.dwd_ord_wide_order_di` 等 5 张线上表，90 天窗口
- 明细来源：中高危设备名单（temp 表）关联订单/支付/结算/票维度
- 退款金额：`COALESCE(支付表, 结算表)` 双源（v2 数据修复后矛盾社区从 599 降至 38）
- 赔付金额：comp 表 `total_amount`（订单维度总赔付，pay_success 状态）——唯一口径

## 五、团伙维度：三类团伙图谱

### 5.1 团伙全景

![团伙全景](charts/04_gang_overview.png)

### 5.2 指纹团伙（行为指纹聚类）——换马甲识别

**方法**：设备行为指纹（航线 N-Gram + 金额档 + 航班号），MinHash 128 位签名 + LSH 加速聚类，Jaccard ≥0.30 连边。

**发现**：130 个指纹团伙，其中 **13 个跨实体社区**——这是"换马甲"团伙的铁证：实体图（IP/证件/手机）把他们拆进了不同社区，但行为指纹证明是同一伙人。

**最典型**：F25 指纹团伙——14 台设备 / 1,811 单，横跨 5 个实体社区 [35|140|779|784|849]。这是"打散实体逃避关联检测"的教科书式操作，建议优先核查。

### 5.3 航线团伙（双图融合）——航线习惯聚类

**方法**：设备-航线二部图 Leiden（≥5 单/航线，剔除 >30 台共享的枢纽热线），与实体图/套利信号融合。

**发现**：23 个高置信团伙，分两类：
- **实体对齐型 10 个**：与实体社区对齐 ≥40%，双图互相印证
- **未入图型 13 个**：设备分层为中风险未进实体图，纯靠**套利率 ≥30%** 通道捞出——这类是实体图盲区团伙（无共享实体但航线习惯一致且套利密度高，如团伙 71 套利率 37.5%、团伙 96/117 达 50%）

### 5.4 团伙跃迁（跨周期演化）

**方法**：上周期（26.05.29 数据）与本周期团伙对齐，计算实体重叠（Jaccard）+ 设备存活率 + 行为指纹相似度（0.4/0.2/0.4 加权）。

**发现**：31 对跃迁（转型 18 / 弱关联 13）。最扎实的延续团伙：
- **P2974 → C7**：31→21 台，设备存活 41.9%，实体重叠 0.083——半数设备延续但实体大量更换，典型"换壳存续"
- **P1847 → C213**：8→10 台，设备存活 50%

## 六、重点排查清单与策略

### 6.1 立即处置（证据链完整）

| 对象 | 规模 | 证据 | 前端路径 |
|------|------|------|---------|
| 机器行为设备 | 651 台 | 三信号（整点对齐/时间差矛盾/超高频），Top 设备单分钟 312 单 | 高危分析 → 筛选"批量机器操作" |
| 内网 IP 命中设备 | 1 台（87e1e1f841307fa9） | 名单 IP 下单 2 单 + 机器行为 | 内部IP 页签 |
| 社区 12 全员 | 61 台 | 五标签复合 | 高危分析 → 搜索 12 |

### 6.2 重点核查（隐藏风险）

| 风险 | 对象 | 为什么是隐藏风险 |
|------|------|----------------|
| **换马甲团伙** | F25 等 13 个跨社区指纹团伙 | 实体图看不见（已被拆散），只有行为指纹能关联——若只按社区处置会漏掉 |
| **实体图盲区团伙** | 13 个未入图型航线团伙 | 设备是中风险（未达高门槛），无共享实体，靠套利密度证明团伙性——现有社区风控完全覆盖不到 |
| **舱位套利网络** | 2,861 台设备 | 同航班同舱位批量订再退款（SC4909 三舱位退款率 73-94%），单看设备无异常，跨设备聚集才暴露 |
| **换设备团伙** | 331 个实体存活团伙 | 上周期设备消失但实体还在——新设备可能会在下一周期爆发 |

### 6.3 策略建议

1. **分层处置**：高风险 2,677 台按"机器行为 > 套利嫌疑 > 黄牛聚集"优先级分批处置；中风险 18,694 台进入观察名单（重点看套利和档位聚集标签）
2. **团伙维度立案**：对 23 个航线高置信 + 13 个跨社区指纹团伙按"团伙"而非"设备"立案——打击设备会被换，打击团伙（实体+指纹双追踪）才有效
3. **赔付审核加严**：对 1,779 台套利嫌疑设备的赔付申请增加人工审核（全额退+快退特征前置拦截）
4. **航线监控规则**：对"同航班同舱位 ≥3 设备聚集且退款率 ≥50%"配置线上实时监控
5. **周期性复跑**：本报告全管线支持 90 天滚动——跃迁检测可持续输出团伙变形追踪

## 八、附录：口径与算法说明

### A1. 风险分层

- **规则引擎 7 条**：机器退款 / 短时退款 / 多账号 / 多支付工具 / 黄牛聚集 / 拦截聚集 / 多乘机人
- **6 模型投票**：iForest / OCSVM / LOF / XGBoost / LightGBM / RandomForest（伪标签训练，反泄露设计：软标签+特征剔除+硬标记富集度评估）
- **分层**：高 = 异常票 ≥2 且规则 ≥2；中 = 异常票 ≥1 且规则 ≥1

### A2. 退款口径（v2 修正版）

`refund_order_cnt` 为主（status IN 39,95,93,31,30 口径已知低估 22%——status 5/7/2 也是退款态）；
`min_refund_pay_interval_sec` 非空时至少计 1（时间差表不受 status 影响）。
退款**金额** = COALESCE(支付表 pp_pub, 结算表 dl_income)。

### A3. 赔付口径（唯一）

comp 表 `total_amount`（订单维度总赔付，pay_success 状态）。AVG≠MAX 判多条求和、单条取本身。

### A4. 社区发现（Leiden）

- **实体图**：设备共享 IP/证件/手机/userId 连边（≥2 实体才连边，热点实体 >20 设备过滤），仅高风险设备入图，最小社区 3 台
- **航线图**：设备-航线二部图，≥5 单/航线，剔除 >30 台共享的枢纽热线
- **指纹图**：MinHash 128 位 + LSH（band=32/r=4），精确 Jaccard ≥0.30 连边

### A5. 套利率（arb_device_ratio）——三层链路

1. 订单级：全额退（|退款| ≥ 订单金额×0.95）AND 快退（支付后 ≤3600 秒申请退款）
2. 设备级：套利单 ≥2 OR（全额退率 ≥50% 且退款 ≥5 单）
3. 团伙级：套利设备数 ÷ 团伙设备总数

### A6. 跃迁指标

- **实体重叠**（entity_jaccard）= |P 实体集 ∩ C 实体集| / |并集|，实体 = IP/证件/手机/userId 四类
- **指纹相似**（fp_similarity）= 0.4×Jaccard(航线bigram) + 0.2×Jaccard(金额档) + 0.4×Jaccard(航班号)
- **形态判定**：实体延续（jaccard≥0.15 或存活率≥0.3）× 习惯延续（fp≥0.25）→ 延续/换马甲/转型/弱关联
